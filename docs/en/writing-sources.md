# Writing references and reuse decisions

The style guide was written for Pixstride after reading the core rules, examples, and license
declarations below. The review is pinned to commits observed on 2026-10-18. No upstream Skill file,
phrase dictionary, or third-party example is bundled or installed in this repository.

| Reference | Reviewed revision and license | Applied judgment |
|---|---|---|
| [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop/tree/8da1f030185bdfe8471220585162991eaeb970e9) | MIT; copyright 2025 Hardik Pandya. [License](https://github.com/hardikpandya/stop-slop/blob/8da1f030185bdfe8471220585162991eaeb970e9/LICENSE). | Prefer specific statements and remove staged rhetoric. Do not import blanket adverb/passive/question bans or replace explanations with slogans. |

[License](https://github.com/Gawg-AI/stop-slop-cn/blob/bdbd9cceaec791f2bd280b4a387a69be09b742d6/LICENSE). | Prefer verbs and concrete subjects, review formulaic prose. Keep uncertainty; do not invent numbers, force sentence rhythms, or automatically strengthen tentative conclusions. |

Treat subjective typography choices as review advice. |

Read scope: both stop-slop projects' `SKILL.md` and before/after examples; the technical guide's text,
headings, paragraphs, numbers, punctuation and document organization; Sparanoid's core spacing,
punctuation, naming and controversy sections. Source snapshots are retained privately for provenance.

## Project Skills

An optional project Skill could point agents to the same two project guides. It adds little value
while [AGENTS.md](../../AGENTS.md) already supplies portable, explicit entry points. No project Skill
is installed. Future adapters must not become the only source of critical rules.

If upstream files or substantial text are later copied, review the exact pinned license, retain its
copyright and permission notices, and record modifications/provenance as required. A reference link
alone is not a substitute for those obligations. Upstream licenses apply to those works; they do not
select Pixstride's project license. All rewrite examples in the project guide use Pixstride's own
preserved drafts and keep their technical qualifications.
