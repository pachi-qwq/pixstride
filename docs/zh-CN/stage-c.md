# Stage C：超大 PNG 路径

Stage A、Stage B 已合并。Stage C 已对私人 48000 × 32000 PNG 完成完整缓存构建和程序化 D3D11 视口验证，
负责人也已确认 Windows 桌面上的缓存命中运行正常。详细视觉验收及其余压力测试仍待完成。

## C1 行解码原型

`large::stream` 用 `png 0.18.1` 逐行读取非隔行静态 PNG，将 RGB、调色板和灰度输入展开为 8-bit 通道，再把借用的行
转换成预乘 BGRA8，不分配完整位图。初始路径不支持 Adam7、APNG、16-bit 通道、ICC 和 HDR。
CPU 转换对编码值四舍五入，不做线性光颜色处理。

解码器有 64 MiB 尽力限制，调用方另设 4 MiB 行限制。块头预检使用检查过的 64 位偏移，限制单个附加块 1 MiB、合计
8 MiB，并限制块数。PNG 解码验证 CRC 和 Adler 校验，不解释忽略的文本和 ICC 内容。取消在块头与行之间检查，无法抢占
已经阻塞的文件系统读取。这些限制不能证明进程所有分配都有硬上限。

生成的小型 RGBA 图片逐行结果与 WIC 对比，预乘舍入差异不超过一个通道值。CRC 损坏、截断、超量元数据、取消和算术
限制测试通过。显式 Release 诊断分别用独立进程扫描生成的 8192 × 256、8192 × 8192 PNG：两者输入与输出行容量均为
65,536 字节，峰值工作集均为 10,022,912 字节；扫描分别耗时 13.698 ms、422.538 ms。这只验证高度增加 32 倍的样本，
不覆盖所有 PNG 编码和异常输入分配模式，没有读取私人极限图片。

## C2 磁盘金字塔

一次行扫描构建所有向上取整减半的层，直到 1 × 1。2 × 2 Box Filter 平均预乘的编码通道，奇数边缘重复取样。
内存只保留行，不保留完整层。Tile 带一像素邻接边框；测试用独立小图参考校验所有层，并检查第零层全部边框和不满整块的边缘。

暂选 1024，仍属实验配置。生成的 2049 × 1537 RGBA 在 Release 单次运行得到：

| 边长 | Tile 数 | 数据字节 | 构建 ms | 热缓存重开 ms | 逆序读 Tile ms |
| --- | --- | --- | --- | --- | --- |
| 512 | 38 | 16,986,000 | 386.591 | 0.328 | 4.173 |
| 1024 | 19 | 16,910,888 | 436.699 | 0.342 | 3.955 |
| 2048 | 14 | 16,875,968 | 513.083 | 0.311 | 3.738 |

这是文件系统热缓存下的单次样本，不是百分位或 GPU 上传测量。保守自有缓冲估算分别为 1,189,994 / 4,343,154 /
12,752,050 字节，不含解码器分配。1024 样本 Tile 经 PNG 压缩从 4,210,704 降至 1,192,620 字节，但增加编码
135.821 ms、解码 4.321 ms。初版使用原始 PBGRA8 缓存，以磁盘空间换取简单、有界的读取。

`pixels.bin` 保存带边框的 Tile；`index.bin` 保存格式版本、尺寸、源身份、由检查过的几何推导的层级、64 位偏移与长度、
Tile CRC32，索引另有 CRC。读取前验证长度和几何，读取每块时再验证其 CRC。默认磁盘总预算 2 GiB，Builder 预算
128 MiB（含解码器额度），磁盘另留 1 GiB 空间。这些估算不是进程内存的硬上限。

根目录文件 lease 串行化构建、打开与清理。活动读句柄阻止淘汰。完成的数据和索引同步到磁盘，再通过同卷目录重命名发布；
取消会清理半成品。后续构建清理可识别的遗留半成品。无效索引会重建；Tile CRC 错误会报错，需清理该缓存后重建。
构建需要空间时按最旧顺序淘汰已发布缓存，没有引入 LRU 数据库。其他进程正在构建同一根目录时返回忙错误，不做无界等待。

源验证比较规范路径、长度、修改时间及首、中、尾各 64 KiB 的 CRC32。构建期间只读句柄拒绝源文件写入和删除，发布前复查
身份。若变化不在抽样范围内且元数据未变，仍可能漏检；CRC32 也不是密码学内容身份。版本变化、抽样内容变化、活动缓存保护、
损坏、溢出和构建中断测试已通过。

在 C2 检查点，私人原图只查过文件属性。负责人已批准 C3 通过后进行独立 10 GiB 缓存实验，1024 金字塔预计 8,224,561,220 字节。
在此检查点尚未读取原图像素。

```powershell
cargo test --release --locked release_tile_sizes_probe -- --ignored --nocapture
```

## C3 查看器集成

超预算 PNG 在 WIC 分配像素前路由到行构建器。普通 JPEG/PNG/BMP 保留 WIC、CPU/GPU 缓存及 Generation。
未缓存 PNG 增加小型块头读取，先检查云占位属性；此类 PNG 需用户先下载到本地。超大 JPEG/BMP 和新路径不支持的 PNG
编码仍返回错误。普通预算保持单图 256 MiB、CPU/GPU 缓存各 512 MiB。

首次大图请求才启动单个 Tile Worker：一个最新构建槽、一个最新视口槽、最多两项答复和 64 MiB CPU Tile LRU。
答复、活动上传和预览可额外持有有界 Tile 缓冲。渲染线程独占独立的 128 MiB Tile GPU 缓存。最多请求 24 个可见 Tile，
特别大的视口会降到更粗层。Builder 的 128 MiB 额度含解码器预算，OS 文件缓存和分配器开销另计，没有引入 IPC。

选择 Generation 淘汰旧源任务，已有 Render Snapshot 序号淘汰旧视口任务。取消在行和 Tile 之间检查，不能抢占阻塞读取。
关闭最多等待两秒，再分离不持有 HWND、GPU 接口且无法再访问 UI 事件的 Worker。下次构建清理可识别的半成品。设备失败
保留报错退出方式，设备重建和实际 Device Lost 压力测试尚未验证。普通 Tile 分配失败会保留可用的粗预览并非模态报错，
尚未注入真实 GPU 分配失败；Tile Worker panic 后拒收后续构建并提示重启。

每个可见逻辑区域只画一次：Tile 就绪则采样该块，缺块则使用预览对应的 UV，不在相同预览像素上叠加高清 Tile。
一像素边框避免采样到无关数据。首次完整预览目前要等待全流扫描、金字塔写入、校验及原子发布；没有实现半成品续建，
也不承诺首开提前显示完整预览。

**F** 适应窗口，**1** 原始像素。大图路径中，滚轮围绕窗口中心缩放，鼠标左键拖动平移。Resize 更新可见 Tile，最小化暂停
绘制。Worker 等待条件变量，渲染器保留事件驱动等待。

Release HWND/D3D11 诊断使用生成的 20000 × 65 PNG：构建 122.490 ms，热缓存元数据重开 0.331 ms，选择到预览
Present 返回首开 123.681 ms、缓存命中 1.886 ms。Tile 读取/CPU 查询 P50 为 61 µs（11 个样本），上传 P50 为
131 µs（13 个样本），Tile GPU 峰值 1,724,772 字节。合成样本不足以得出稳定长尾百分位。GPU 回读检查跨 Tile 边界的
17,425 个像素，含预乘 Alpha 合成，差异不超过两个通道值。Fit/原始尺寸、平移、缩放、最小化/恢复、缓存重开、构建期间
普通 GPU 命中切换和关闭均已程序化执行。这不等于人工视觉验收，也不是 Input-to-Photon 测量。

```powershell
cargo build --release --locked
$env:PIXSTRIDE_TILE_CACHE = Join-Path $env:PIXSTRIDE_TEST_ROOT 'viewer-cache'
& .\target\release\pixstride.exe $env:PIXSTRIDE_STRESS_IMAGE
cargo test --release --locked release_large_viewer_probe -- --ignored --nocapture
cargo test --release --locked release_tile_gpu_readback -- --ignored --nocapture
```

两个路径变量均应指向 Git 外。默认缓存为 `%LOCALAPPDATA%/Pixstride/tiles-v1`。使用专用根目录，不能指向源图目录。
`PIXSTRIDE_TILE_CACHE_GIB` 接受 1–10，默认 2，超过 2 需负责人单独批准。真实实验已得到 C3 通过后使用 10 GiB 的批准，
后续 C4 结果见下节。人工验收仍需检查真实图片的接缝、透明度、连续手势、任意区域、取消和反复打开/关闭。

## C4 真实样本结果

C3 通过后，负责人批准在专用本地目录使用 10 GiB 缓存。读取前重新检查驻留标志和可用空间。源文件只读打开，没有复制或
上传，结束后长度和修改时间未变。样本为非隔行 RGBA8 PNG，48000 × 32000，文件 2,071,102,933 字节；完整 RGBA8
位图需要 6,144,000,000 字节。

| 测量 | 结果与边界 |
| --- | --- |
| 首次完整构建 | 755.866 s；行扫描及金字塔写入 750.860 s，之后执行 CRC、同步和发布 |
| 持久缓存 | 2,027 个 Tile；数据 8,224,561,220 字节 + 索引 81,228 字节 + 8 字节归属标记 |
| Builder 进程 | 峰值工作集 16,023,552 字节；抽样私有字节峰值 7,577,600 |
| 源行缓冲 | 输入/输出总容量 384,000 字节，没有完整位图 |
| 热缓存元数据重开 | 首轮 n=20，P50 0.313 ms、P95 0.470 ms；独立复核 P50 0.408 ms、P95 0.548 ms |
| 四角/中心 Tile 读取 | 第零层五块，含 CRC 耗时 0.123–1.044 ms，文件系统热缓存 |
| 热缓存 Viewer 预览 | 请求到预览 Present 返回 170.994 ms，n=1，含新建 D3D11 Device |
| 视口完成 | n=53，P50 6.993 ms、P95 9.815 ms、最大 133.217 ms；含初始设备/启动等待及 GPU 复用/未命中混合负载 |
| Tile 磁盘读取与 CRC | n=166，P50 0.957 ms、P95 1.071 ms；原始缓存无需解压 |
| Tile GPU 上传提交 | n=167，P50 0.332 ms、P95 0.419 ms |
| Viewer 关闭 | Render/Loader join 及销毁窗口 26.417 ms，n=1 |

RTX 4080 SUPER Hardware Device 返回 Feature Level 11.1。两轮 5 × 5 原始像素视口遍历触发淘汰：CPU Tile 驻留峰值
66,845,952 字节，上限 67,108,864；GPU Tile 逻辑峰值 134,151,296 字节，上限 134,217,728。DXGI 进程本地显存
抽样峰值 174,297,088 字节，含交换链、驱动和其他分配。Viewer 峰值工作集 145,068,032 字节，抽样私有提交峰值
421,969,920 字节。这些值与应用缓存预算不同。没有测量 OS 文件缓存占用，GPU 抽样也不是连续驻留跟踪。

Viewer 诊断只通过大图请求加载获批源，没有扫描私人目录或预加载邻图。真实首建在独立缓存诊断中运行，没有测量真实首建
选择到预览的完整耗时，也没有验证 Viewer 在十二分钟构建期间的持续响应。它提交预览和原始局部，返回 Fit，验证 250 ms
静止期间没有额外 Present，并正常关闭。这不等于人工桌面的接缝或手势体验验收。构建中断使用生成的样本测试，没有中断
私人样本这次十二分钟的构建。

首次构建较慢，运行期间观察到超过一百万次小写入，后续应实验批量写行。没有受控的存储/解码器对照，不能把整个耗时直接
归因于 PNG 解码。没有为了重复计时而重建缓存。工作集数据证明该输入的流式行为，不能证明所有 Decoder/Driver 的进程硬
内存上限。小型 C1 复测也通过限制：高度 256 / 8192 的峰值工作集分别为 10,141,696 / 10,158,080 字节，自有行缓冲
均为 65,536 字节。

普通导航回归通过，含 110 次 GPU 命中、100 次强制 CPU 命中、源替换、读取错误、反向/松键/失焦/新打开边界和繁忙 WIC
Worker。GPU 命中 P50/P95 为 0.241/6.457 ms，CPU 命中为 0.454/5.097 ms。合成长按运行提交 25 张图片，其中
14 张为进度图片，最终目标/Present Generation 均为 61。这些运行与独立缓存构建进程重叠，不是受控的阶段 B 前后对照。
JPEG/PNG/BMP 正确性测试也已通过。

`0e39b64`，阶段 C 使用当前本地构建，主机和工具链相同。每轮包含 110 次 GPU 命中、100 次强制 CPU 命中及错误/过期

## 依赖与依据

`png 0.18.1` 和 `crc32fast 1.5.2` 均采用 MIT OR Apache-2.0。纯 Rust 解码无需部署独立 libpng DLL，且提供逐行 API；
普通 WIC 路径不承诺有界流式读取。image-rs 仓库持续发布变更，并说明有模糊测试；这不等于对 Pixstride 做过安全审计。
没有启用 nightly 特性或使用外部 AI 服务。新增依赖树还包含 MIT 的 `simd-adler32 0.3.10` 和 Zlib 的
`zlib-rs 0.6.8`，其他新增 crate 提供 MIT/Apache 选项。原样声明保存在[第三方声明](../../THIRD-PARTY-NOTICES.txt)，
仅覆盖阶段 C 新增项，不是完整发布清单。本检查点 Release 为 893,440 字节，阶段 B 产物为 596,480；差值包含新增代码和
内嵌 Shader，不能全部归为依赖体积。

参见 [Reader API](https://docs.rs/png/0.18.1/png/struct.Reader.html)、
[Decoder 限制](https://docs.rs/png/0.18.1/png/struct.Decoder.html)和
[维护仓库](https://github.com/image-rs/image-png)。

将 `PIXSTRIDE_TEST_ROOT` 设为仓库外目录后运行显式内存诊断：

```powershell

```

必须得到负责人明确批准。
