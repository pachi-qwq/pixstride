# 术语表

文档统一使用下列名称。维护模块表示计划中的职责划分，不代表查看器模块已经存在。
API 标识符保持原样。

## 平台和图像术语

| 英文 | 统一中文名称 | 含义 |
|---|---|---|
| Win32 | Win32 原生 API | 应用使用的 Windows 桌面窗口、输入和系统 API。 |
| windows-rs | windows-rs | Rust Binding；涉及依赖时说明具体 crate 和版本。 |
| D3D11 Immediate Context | D3D11 即时上下文 | 提交渲染命令的 `ID3D11DeviceContext`，由渲染线程独占。 |
| DXGI Swap Chain | DXGI 交换链 | 窗口呈现所用的缓冲区及呈现状态。 |
| GPU Texture | GPU 纹理 | 例如 `ID3D11Texture2D` 的 GPU 图像资源，应与资源视图区分。 |
| Shader Resource View (SRV) | 着色器资源视图 | 着色器读取资源所用的视图，本身不等于像素分配。 |
| Image Decoder | 图片解码器 | 按明确能力契约读取元数据并输出像素的格式适配器。 |
| Pixel Buffer | 像素缓冲区 | 带有尺寸、格式、行跨度、Alpha、颜色描述和所有权的 CPU 存储。 |
| Stride | 行跨度 | 相邻两行起点的字节距离，含填充，可能大于紧密排列的行字节数。 |
| Premultiplied Alpha | 预乘 Alpha | RGB 乘以 Alpha 后的表示；还应说明传递函数和颜色域。 |
| Tile | 分块 | 某一分辨率级别中的有界区域，应明确边缘尺寸和滤镜边界像素。 |
| Tile Pyramid | 分块金字塔 | 按不同分辨率生成并切块的图像集合，可用层级决定显示细节。 |
| Cache Eviction | 缓存淘汰 | 将条目移出缓存；存活引用仍可能持有底层分配。 |
| Resource Retirement | 资源退役 | 保留已提交的 GPU 资源，等待在途工作完成后才允许复用。 |
| First Build | 首次构建 | 没有有效磁盘缓存时生成预览和分块，与之后的缓存命中分开测量。 |
| Displayed | 已显示事件 | 跟踪工具报告的帧到达显示阶段的事件，不等于光子测量。 |

## 项目概念和生命周期

| 概念 | 定义及用途 | 维护模块 | 创建、更新和释放；与相似概念的区别 |
|---|---|---|---|
| 渲染快照（Render Snapshot） | 最新显示意图的不可变描述，用于分离 UI 状态和渲染任务。 | UI 发布，Render 读取。 | 可见状态变化时创建，新快照替换旧快照，所有读者结束后释放。它描述意图，不表示像素已就绪。 |
| 代际编号（Generation） | 标识某个状态域变化的递增编号，用于拒收过期工作。 | 对应状态域的维护模块。 | 随状态域创建，按规定的失效条件递增，状态域销毁时释放。必须说明所属域，它不等于统一的图像内容身份。 |
| 快照序号（Snapshot Sequence） | 用于排列渲染快照的代际编号。 | UI。 | 窗口会话开始时创建，发布快照时递增，关闭时结束；不标识文件修订。 |
| 设备代际（Device Epoch） | 标识当前 D3D11 设备生命周期的代际编号。 | Render。 | 创建设备时产生，更换设备后更新，释放设备时结束。旧代际的所有句柄失效。 |
| 文件身份（File Identity） | 可获得的文件标识；必要时使用路径后备。 | Navigation/I/O。 | 发现或打开源文件时记录，按需复核。它标识文件，不保证内容不变。 |
| 源修订（Source Revision） | 按文件身份、长度、修改状态和校验策略描述内容有效性。 | I/O/Decoder；Cache 保存该值。 | 读取时记录，发布前复核，源变化时失效。弱元数据可能漏掉内容替换。 |
| 图像键（Image Key） | 由源修订、页或帧、解码器及像素策略组成的缓存键。 | 阶段 B 的 Cache。 | 验证请求时创建，有引用时保留。单独的路径不足以作为键。 |
| 颜色键（Color Key） | 标识颜色转换、目标及策略的键。 | 后续的颜色转换/Cache。 | 选定转换时创建，策略或 profile 改变时更新，派生条目释放时结束；不改变源修订。 |
| 分块键（Tile Key） | 图像键加分辨率级别、坐标、尺寸、边界和派生版本。 | 阶段 C 的 Tile Cache。 | 请求分块时创建，随索引或缓存条目保留；单独的分块坐标不唯一。 |
| 预算预留（Budget Reservation） | 在分配前计费的令牌。 | 对应资源预算的维护模块。 | 分配前预留，成功后确认，失败或最后一个分配所有者释放时归还。多个引用只计费一次。 |
| 在途任务（In-flight Task） | 输出可能被多个请求使用的排队或执行中任务。 | 阶段 B 及以后的任务调度器。 | 未命中时创建，同键复用，只完成或取消一次。过期结果不能修改当前目标。 |
| 缓存租约（Cache Lease） | 标记某一缓存代际正在构建或读取。 | 阶段 C 的 Disk Cache。 | 使用前取得，完成或取消时释放；崩溃恢复时校验过期记录。它不提供通用文件锁保证。 |
| 分块构建器（Tile Builder） | 计划中在预算内解码、降采样并写入分块金字塔的组件。 | 阶段 C 的超大图片路径。 | 仅对符合条件的源启动，验证完成、取消或失败后结束。普通图片不经过它。 |

阶段 A 只在测试需要时使用快照序号和设备代际。其余概念用于说明后续设计，不代表现在可以
实现所有编号、缓存或工作进程。仅在指代实际标识符时使用 `RenderSnapshot`、`DeviceEpoch` 等代码拼写。
